Speaker Notes — CPR+ Town Hall Slide

  • Opening: CPR+ (formerly "WhiteWalker") is our zero-touch endpoint automation framework running silently on ~500K managed Windows devices worldwide. The entire design philosophy is invisibility — if it's working, nobody notices.
  • VPN Blackholing: When a laptop is confirmed on the corporate network, CPR+ sinkholes VPN headend hostnames locally so the client doesn't try to tunnel over itself (hairpinning), which used to cause connection storms and confused users.
  • Haystack: A lightweight, event-driven (not polling) Windows Event Log watcher. Task Scheduler does the "listening," so there's no always-on background loop chewing CPU or battery.
  • Splunk Telemetry: Every major subsystem (main engine, blackhole, captive portal, haystack) writes structured logs that feed our Splunk dashboards directly from the endpoint — giving us real, global, near real-time visibility into remote access health without deploying a heavy monitoring agent.
  • XmlVault: Solves the "island" problem — a device that's lost its VPN profile XML and can't reach NETLOGON to get a new one. CPR+ keeps a local backup vault and self-heals automatically.
  • Auto ISE Rescanning: Historically, users got stuck in an unpostured state on-prem and had to manually trigger a rescan or call the helpdesk. CPR+ detects the ISE redirect and handles the rescan + compliance verification loop automatically.
  • Captive Portal: This is the most user-visible piece by design — hotel WiFi, airport lounges, conference networks. CPR+ detects the portal, launches the browser in the right security context, verifies success, and if it times out, gives the user a one-click retry instead of a blank stare.
  • Closing line: "Our north star metric isn't how many tickets we close — it's how many tickets never get opened in the first place. That's what invisible means."
  • Optional Q&A backup facts: 97.4% automated Pester test pass rate on current release candidate, zero known regressions, ~2-3M automated executions per day across DHCP/wake/unlock triggers, 90% reduction in user intervention vs. legacy manual processes.
